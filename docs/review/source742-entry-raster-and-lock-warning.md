## Entry light field

The three radial gradients, their combined opacity and isotropic blur are
static before the existing rigid drift transform. Previously both the body
and native caption repainted that blur for each sample of the same clock.
They already clipped to their viewports; an absent clip is not the finding.

One field-owned image now retains the transparent blurred light, keyed by
geometry, its three colors and actual view pixel ratio. Both original
painters borrow that image and apply the unchanged drift. The window base
still paints separately. The 40-second cycle, easing, translation, rotation,
60 logical-pixel blur, grouped opacity, clip, route/window/overlay holds and
reference freeze/restoration contracts remain.

The cache holds at most one image of 16,777,216 pixels, with each side at most
8,192 pixels. Oversized geometry uses the original painter without
downsampling. Geometry/color/pixel-ratio replacement and widget disposal
retire the old image. The recorded picture is disposed after creating the
image handle. This is a pixel limit, not a measured GPU-memory claim.

Flutter's pinned [image API](https://github.com/flutter/flutter/blob/3.47.7/engine/src/flutter/lib/ui/painting.dart)
creates the handle synchronously and rasterizes it asynchronously. Creation
occurs in the first original paint; no warm-up, extra clock or timing-window
change is added. Existing drift and theme/disposal cases now also check image
reuse, pixel-ratio replacement and handle retirement. Existing pixel
envelopes, clipping, pause/restoration and caption/owner cases remain.
