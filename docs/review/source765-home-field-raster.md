# Bounded Home field raster

The Home field previously recomputed the same grouped blurred lights on
every animation tick. The Home preset now records that stationary light
layer once and moves the resulting image with the original clock. The
card base remains separate, so switching the theme repaints it without
baking the old base into the image.

One widget-owned image is keyed by field geometry, source colors and device
pixel ratio. It is retired before replacement, when the preset changes or
when the owner leaves the tree. Empty or oversized geometry retires it as
well. The cache is bounded to 16,777,216 pixels and 8,192 pixels per side;
larger requests use the original full-resolution analytic paint instead of
downsampling. The source's forty-pixel blur, .55 group opacity, gradient
centers, enlarged field, rotation and eighteen/thirty-six-second drift
remain. The fragment-shader preset, ShaderClock visibility/frost behavior,
original artwork, values and financial authority are unchanged.

Three hosted widget cases extend the existing entry-field test file. Both
themes exercise the full Home drift under the OS animation flag, image reuse,
the oversize fallback and sampled cached/analytic paint agreement. The
resource case checks theme-base changes, DPR replacement, geometry
replacement and disposal without pending frame callbacks. These are engine
and resource controls, not catalog acceptance or a measured speedup.

The existing file joins strict analysis, taking the unique selection from
274 to 275. It already runs in the early Ready gate and complete non-chain
directory. No workflow, dependency, asset or fixture filename is added.
Fresh full Linux precedes the grouped Windows/image qualification of the
Home and Source764 Plasma/Swap changes.
